## Problem Description

Traditional farming lacks timely data for decision making.  
The Smart Agriculture Monitoring System digitally monitors agricultural conditions such as water supply, soil fertility, insect levels, and pesticide usage.

The system analyzes crop conditions and generates recommendations to improve crop health and yield. It also stores historical recommendation records for future analysis.

---

## How to Run the Code

1. Open the project in Eclipse or VS Code IDE.
2. Compile all Java files inside the `CaseStudy` package.
3. Run `Main.java`.
4. Enter the required inputs through the console.
5. The system generates and stores agricultural recommendations.
6. Output of recommendations is provided.

---
